# 連絡先 API

連絡先は、認証済みの d6e-auth セッション主体ごとに保存される非公開データです。すべての操作には、有効なブラウザセッションと `active` なローカル `instance_member` が必要です。API キー、受信者 capability、受信者セッションではアクセスできません。所有者や組織をリクエストで指定することもできません。

## エンドポイント

| メソッド | パス                           | 用途                         | `Idempotency-Key` |
| -------- | ------------------------------ | ---------------------------- | ----------------- |
| `GET`    | `/api/v1/contacts`             | 自分の連絡先を一覧表示       | 不要              |
| `POST`   | `/api/v1/contacts/search`      | 自分の連絡先を検索           | 不要              |
| `POST`   | `/api/v1/contacts`             | 連絡先を明示的に保存         | 必須              |
| `PUT`    | `/api/v1/contacts/{contactId}` | 指定バージョンの連絡先を置換 | 必須              |
| `DELETE` | `/api/v1/contacts/{contactId}` | 指定バージョンの連絡先を削除 | 必須              |

一覧は `cursor` と `limit` のみをクエリパラメーターとして受け取ります。検索は、名前やメールアドレスの断片を URL や通常のアクセスログへ残さないよう、厳密かつサイズ制限された JSON 本文 `{ query, cursor?, limit? }` を受け取ります。両方の応答は `{ items, nextCursor }` です。カーソルには所有者スコープの連絡先 UUID だけが入り、氏名、メールアドレス、検索語は入りません。

## データと更新

公開される連絡先は `{ id, email, name, locale, version, createdAt, updatedAt }` です。`name` は表示名、`locale` は受信者の希望言語（`en` または `ja`）です。メールアドレスは受信者入力と同じ規則で空白除去と小文字化を行い、同じ所有者の中で一意にします。

- 作成本文: `{ email, name, locale }`
- 置換本文: `{ email, name, locale, expectedVersion }`
- 削除本文: `{ expectedVersion }`

作成は `201 { contact }`、置換は `200 { contact }`、削除は `200 { deleted: { id, deletedAt } }` を返します。安全な再実行では `Idempotency-Replayed: true` が付きます。別の正規化済みリクエストで同じキーを再利用すると競合になります。存在しない ID と他の所有者の ID は、同じ不透明な `404` として扱います。

連絡先は「連絡先に保存」を明示的に実行した場合だけ作成・更新されます。受信者の入力、エンベロープの準備、送信から自動保存することはありません。連絡先を選択すると氏名、メールアドレス、希望言語だけを受信者下書きへコピーし、役割と送信順序は変更しません。連絡先を更新または削除しても、既存エンベロープの受信者情報や証跡は書き換えません。
